# Bibliografía y recursos de investigación

Esta carpeta está destinada a centralizar el material de consulta y las fuentes utilizadas para el desarrollo del Trabajo Práctico.

## ¿Qué podemos incorporar?

Material que considere relevante para la investigación:

- Artículos académicos y publicaciones científicas.
- Informes y documentos en PDF.
- Enlaces a sitios web y fuentes oficiales.
- Videos, conferencias y tutoriales.
- Otros recursos que contribuyan al desarrollo del trabajo.

**Importante:** Priorizar fuentes confiables, verificables y relacionadas con el tema de investigación.

## Enlaces y recursos compartidos

Para mantener el material organizado, registrar los enlaces utilizando el siguiente formato:

| Recurso | Enlace | Descripción / utilidad | Aportado por |
|---|---|---|---|
| Ejemplo: Informe estadístico | [Ver recurso](https://www.indec.gob.ar/) | Fuente de indicadores económicos | Integrante |



_Pueden subir directamente archivos PDF u otros documentos relevantes a esta carpeta._
